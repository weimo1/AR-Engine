# scene 模块

状态：2026-10-23局部职责边界已确认；尚未实现。确认来源见[总体架构确认记录](../../总体架构与技术路线.md#2026-10-23-架构确认记录)A2、A4，当前文档任务见[范围](../../../openspec/changes/architecture-record-confirmed-boundaries/proposal.md)。

scene持有权威场景数据：对象、层级、变换、相机、灯光及资产引用。GPU句柄和描述符槽位不进入场景权威数据；runtime读取scene并转换为render输入。render不回读EnTT或保留组件地址。

场景变化表达事实，render消费者决定GPU记录、历史与缓存更新。具体变化通知、标识、序列化、借用期及资产所有权仍待设计；不因文档入口存在就创建代码模块。资产详细设计延期。

主契约及图ARCH-DATA-02只维护于总体架构。后续检查覆盖父子变换、多实例独立修改、移除及场景切换；尚未运行，不改变[P0范围](../../../openspec/changes/bootstrap-engine-p0/proposal.md)。

相机参数/关联变换与派生矩阵/历史的具体归属见R2 [architect建议](../../总体架构与技术路线.md#2026-10-27-待确认的职责澄清建议)，待用户确认；不由模块入口自行扩大A2/A4确认。
