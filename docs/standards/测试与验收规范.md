# 测试与验收规范

文档 ID：TEST-001。修订：草案 1。日期：2026-10-18（Asia/Shanghai）。状态：待确认；当前讨论文档规则，不表示测试设施已部署。

依据：[AI 任务执行规则](AI任务执行规则.md)、[诊断与证据方向](错误异常断言与日志规范.md)、[验证计划模板](../archive/2026-10-19/templates/07-验证计划.md)、[验证记录模板](../archive/2026-10-19/templates/09-验证记录.md)。本文细化检查策略，不变更既有需求和验收边界。

## 1. 先定义可判定的预期

实施前，AI 将任务对应到需求验收项，写清输入、可观察结果、检查方法与回归范围。可以写在模块方案或已有任务记录中，不要求每次新建文件。预期由已确认需求、数学契约、可解析参考解或有效基线支持，不能只把当前输出保存为正确答案。

没有可判定的预期时，记录尚缺什么证据；代码能编译、进程没有崩溃、日志没有 Error 或画面看起来正常，都不能单独证明整个功能完成。

## 2. 按行为选择验证

| 变更 | 首选证据 | 需要补充的边界 |
| --- | --- | --- |
| 数学、索引、状态转换等纯逻辑 | 独立已知输入/输出、边界与失败用例 | 不只用生产函数反算自身生成预期 |
| 资产、场景、配置与文件操作 | 受控文件集、往返一致性、错误输入与失败清理 | 不修改用户原始资产，不只检查文件存在 |
| Shader、布局、绑定与 GPU 数据 | 编译/接口核验及适用 GPU 已知值检查 | 不能只凭 SPIR-V 验证成功判断算法正确 |
| 渲染效果 | 固定场景、数值检查、适用参考图与差异附件 | 同时核对输入与输出编码，保留视觉复核 |
| 编辑器交互 | 真实操作结果与保存/重开等端到端检查 | 核对引擎状态，不以截图按钮出现等同操作有效 |
| 性能与优化 | 正确性证据加同条件样本比较 | 没有可比较基线时先建立测量，不编造收益 |

测试粒度按实际架构选择；不规定所有类型必须有单元测试，不追求没有业务含义的统一覆盖率数字。

## 3. TDD 采用边界

对需求明确、输入输出稳定的纯逻辑和可复现缺陷，优先 TDD：先让同一验收测试因目标行为缺失而失败，再实现，通过后重构并复验。保存适用的源码/补丁标识与结果；环境损坏、编译器缺失不是有效的功能 RED。

探索性 GPU 原型可以先实验，再把确认的行为与退出条件变成检查；如实记录未先写测试，不补造 TDD 历史。低影响可逆修改、格式和纯注释不强制新增测试；已有相关检查仍按实际影响执行。不要求用测试镜像每个函数的内部实现。

## 4. 图像与数值

固定适用的场景/资产版本、相机、分辨率、效果设置、随机种子、帧或采样策略，以及构建、GPU、驱动和输出编码。时间与随机效果按其机制控制或设计统计判定，不靠无限增加阈值消除差异。

优先给关键行为构造可解析证据：已知近远位置与遮挡、深度重建、法线方向、颜色编码参考值、资源索引与缺失纹理等。数值只证明其覆盖范围，不能代替整个画面的检查。

参考图应注明来源及其适用环境。比较记录实际输出、参考图、差异图、指标与容差；算法、颜色、遮罩区域和阈值依据写入对应计划，不统一承诺跨 GPU 像素完全相同。检测到差异时，先定位原因，再判定缺陷或预期变化。

AI 不得在功能修复中顺手替换图像基线、扩大容差或屏蔽错误区域以获得通过。基线确需更新时，提供旧/新/差异及原因，经适用审查；若改变需求、视觉目标或验收，按用户确认边界处理。证据不足以裁决视觉目标时标记待判定，不写通过。

## 5. 运行状态与失败

统一使用 passed、failed、blocked、not_run、not_applicable，沿用验证记录模板。GPU 缺失、feature 不支持、工具故障或超时分别记录；必需检查缺证据不能进入完成状态，真正不适用项说明依据。

重试应有可解释原因与预算，保留首次失败和各次结果；不能反复运行直到偶然通过后只报告成功。尚未解决的不稳定检查记录影响，不以“偶发”直接豁免。测试进程设置有限运行预算，拥有独立输出和可证明的清理边界。

## 6. 回归与交付

局部变更检查直接行为和受影响调用方；公共头、include、布局、依赖和构建配置变化扩大到实际消费者与相关配置。依赖分析不足时说明并扩大合理范围，不每次机械执行所有 GPU 和性能场景。

交付关联任务、源码状态、配置、检查标识、命令、结果与原始证据。AI Review 复核需求/契约、实现和验证是否相符；审查通过不代替测试，测试通过也不代替审查。

优先复用已有计划和记录模板，避免重复维护另一套结果事实。CPU 测试框架已选 Catch2；引擎 Harness 接口、场景、数值容差、图像算法、超时与资源配额待对应技术方案具体落实。
