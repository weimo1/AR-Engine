# ADR-0003：主视图深度采用 Reverse-Z

状态：方向已确认，数学与渲染状态细节待方案。日期：2026-10-18（Asia/Shanghai）。

后续补充：用户明确选择 GLM 并要求本轮其余数学/颜色约定沿用 Flower，主视图的有限 RH/ZO 投影、负高度 viewport、D32_SFLOAT、清零和静态网格 GREATER_OR_EQUAL 已记录于 [数学、坐标与颜色规范](../standards/数学坐标与颜色规范.md)。下方为原决策记录；本补充明确的条目不再视为完全未定，其他 Pass 与实际运行验证仍需各自方案。

## 背景与决策

用户明确提出“使用 rever z”，记录为实时主视图深度采用 Reverse-Z（反向深度）约定，核心含义是将近处映射到较大深度、远处映射到较小深度。

## 待技术方案确定

- 投影矩阵、Vulkan 深度与视口约定、近远平面、深度格式。
- clear 值、比较操作、深度写入以及是否需要 GREATER/EQUAL 等具体状态。
- CPU 剔除、Shader 深度重建、调试视图与后续效果的统一契约。
- 阴影图和其他特殊深度用途是否采用同样约定，逐项分析，不自动推广。
- 数值、固定几何场景及图像验证；不只检查管线状态值。

常见做法是清零深度并使用更大值通过的比较，但这些配套参数仍需随投影和具体 pass 一起确认。本 ADR 不单独决定手性、矩阵存储/乘法顺序、无限远平面或所有深度 pass 的实现。
