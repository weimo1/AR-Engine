# ADR-0005：数学库采用 GLM

状态：选型已由用户确认，尚未集成。日期：2026-10-18（Asia/Shanghai）。

## 决策与来源

用户明确要求“用glm 就行了 其他的 你就按照flower 的走”。采用 GLM 作为 CPU 向量、矩阵、四元数与相关数学运算库；当前讨论中的坐标、矩阵、深度和颜色约定沿用本机 Flower 的对应实现，核查结果见 [数学、坐标与颜色规范](../standards/数学坐标与颜色规范.md)。

“其他”按本轮数学与颜色议题理解；不将该指示扩展为采用 Flower 全部架构、功能、依赖和编译失败弹窗行为，也不将此前所有 Shader 草案自动标为已确认。

## 约束与实施

- GLM 配置集中维护，保证相关编译单元在首次包含 GLM 前使用一致配置。
- CPU 数学类型不能自动充当 GPU 数据布局证明；继续执行字段偏移、stride 和适用读回核验。
- GLM 固定版本、依赖接入、实际所需扩展、ABI/对齐配置与编译检查在基础建设阶段落实，本轮不下载或安装。
- 不照抄参考源码中的错误类型接口或不准确注释；按已经核实的数学语义实现，实际差异留有记录。

参考：[GLM 官方手册](https://github.com/g-truc/glm/blob/master/manual.md)。该链接随上游变化，实施时固定版本；选用 GLM 不代表已验证具体工具链组合。
